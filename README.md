# 👑 ForMyQueen

> A little world, made with love, just for my queen. ❤️

**ForMyQueen** یک بازی ویدیویی است که به‌عنوان هدیه‌ای شخصی برای پارتنرم توسعه داده‌ام.

این پروژه تلاشی برای تبدیل احساسات به یک دنیای قابل‌بازی است؛ دنیایی با فضای فانتزی سلطنتی، شخصیت‌ها، روایت داستانی و موسیقی اختصاصی که با عشق برای یک نفر خاص ساخته شده است.

از طراحی و پیاده‌سازی بازی گرفته تا ساخت موسیقی، این پروژه فرصتی بود تا ایده‌ها و علاقه‌ام به بازی‌سازی را به هدیه‌ای واقعی تبدیل کنم.
